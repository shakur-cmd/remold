What the reference actually does

The real PR comment presents baseline, candidate, difference and enforced ceiling for two provider fixtures. Its five enforced metrics are total thread wire bytes, initial thread snapshot wire bytes, live-turn WebSocket wire bytes, decoded bytes and message count. This particular gate measures transfer volume; it does not establish an all-purpose timing or user-productivity benchmark.

The server integration test exercises HTTP and WebSocket paths with synthetic historical turns and retained tool results, produces structured evidence and fails when the budget evaluator reports a violation. CI uploads the result even when a test fails. A separate trusted workflow validates artifacts and compares the PR with a main-branch baseline before updating the comment. The reporting workflow does not execute PR artifacts.

Remold follow-on acceptance

  • Use repeatable, representative workflows on synthetic data: opening a record list, filtering/searching, opening a large activity timeline, receiving an agent result and reconnecting a live view. Retain correctness checks alongside performance measurements.
  • Report baseline and candidate commit, fixture version, environment, measured values and differences. Include transfer volume, update/message counts, backend work and relevant user-visible timing. Label unmeasured values rather than invent them.
  • Derive Remold’s ceilings from measured baselines and explicit product expectations. Keep deterministic size/work-count gates distinct from noisy elapsed-time measurements; use repeated controlled timing samples before declaring a meaningful slowdown.
  • A deliberate regression must fail the check. Missing or incompatible evidence cannot silently pass. Changing a ceiling requires a visible rationale and review, not an automatic baseline reset.
  • Publish an HTML evidence report and a concise PR comparison. Exceeding an enforced ceiling blocks the release path. Connect release versions and accepted improvements to the measurement dashboard.
