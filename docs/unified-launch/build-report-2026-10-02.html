What went wrong and was fixed on the way

  • The independent checks did their job: every milestone failed its first check, and every failure was reproduced before it was fixed. Examples: an agent could clear a protected field by deleting a linked record; demo cleanup could delete a real company that shared a demo name; a replayed request could show data after access was revoked; funnel date filters were off by a day around daylight saving.
  • One defect was mine: a round-1 instruction I gave on request replay caused the round-3 lead intake defect. The corrected rule is in the decisions log.
  • Two real-world failures only showed up live. The backup script ran the Convex CLI in an empty folder, which the real CLI refuses. Creating the intake key from the CLI was blocked by a signed-in-owner check. Both are fixed, the second through a reviewed change.
  • Codex hit its usage limit (resets 2026-10-04 00:05). Astra checked most of the work; from then on Claude Fable 5.1 checked, which is still a different model from the Opus builders.
  • A worker script bug (not executable, and an early exit) delayed five fix rounds and hid two finished builds for a while. Both are fixed.
