# Save to Remold (Chrome extension)

Click the extension (or press Alt+Shift+S) on a LinkedIn profile, a LinkedIn company page, or any business website. A small Remold window opens with the name, title, company and link filled in. Check it, add a note, and press Save.

The extension holds no key and no login: the window is Remold itself, so it uses the session you are already signed in with.

## Install

1. Open `chrome://extensions` (or the same page in Helium, Brave or Edge).
2. Turn on Developer mode.
3. Click "Load unpacked" and choose this `extension` folder.
4. Pin "Save to Remold" to the toolbar.
