3. Mark both pages "Draft, not yet reviewed" at the top until Shakur approves. Link them from the sign-in page footer.
4. Subscription billing scaffold, TEST MODE ONLY: Stripe Checkout (subscription) session creation for the workspace owner and a webhook endpoint that verifies the Stripe signature and sets one per-workspace access flag (active / past_due / canceled). No access enforcement yet beyond showing the status in Settings (enforcement is a later decision). Tests with a stubbed Stripe client and real signature verification using a test secret.
