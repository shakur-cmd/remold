What the builder overstated

  • "A tampered snapshot changes the canonical hash." This is true, but nothing acts on it. An edited snapshot that is still schema-valid restores, passes the drill, gets a PASS receipt and passes preflight. Only a tamper that breaks the schema is refused. See raw/probe-drill2.json: tamperedTitle PASS, emptiedAppTables PASS, invalidDoc FAIL.
  • "Passes only with a receipt bound to its commit/schema/build." That binding holds. But the receipt is not bound to a real or current backup. The gate proves "some snapshot restored under this schema", not "production data restores under this schema". See raw/release-alterations.txt.
  • "Real free-plan exports of both previews." They are real exports, but tiny. The PR4 export has 1 user and 1 record. The 250-record synthetic fixture is the larger test.
  • "Old browser." This is a page loaded before expansion. It uses the same convex client version as the new code, not an older client library. The builder disclosed that it is not the React/AuthKit app.
