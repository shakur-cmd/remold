Source review

The schema change is additive. Fixed route/status labels and bounded source-controlled release labels keep aggregate cardinality finite. Absolute-minute indexing avoids ring reuse races. Minute-range reads are bounded; stale data cannot enter recent results, and purge/opportunistic expiry constrain retention. Counter mutations are internal. The HTTP wrapper measures through response construction and catches scheduler errors separately.

Convex’s scheduled-function documentation supports the exactly-once scheduled-mutation design. A successfully scheduled mutation can still fail on invalid application logic; the report correctly states observed delivered spans rather than complete traffic.

The operator report keeps observed totals separate from explicit coverage. A covered minute proves a canary, not every request. Missing transport and missing collector evidence remain explicit; zero samples yield null rates/percentiles. Histograms return upper bounds rather than interpolated quantiles. The independent overflow probe confirms null p95 with actual samples above the maximum bucket, alongside the documented overflow meaning.

Measured overhead and remaining limits

Alternating local blocks retained20 enabled and20 disabled client samples. Mean client time was 6.878 ms enabled and 5.495 ms disabled. These are noisy local observations, not causal or production overhead guarantees. Raw samples are retained.

Backend release remains unknown pending exact artifact SHA pinning. No true release comparison is certified. Operator access remains internal-admin; no public platform role or tenant dashboard was added. Delivered alerts, long-term comparisons, masked business metrics, native platform total reconciliation and production cost/throughput remain open. Canary checks do not detect random partial loss or crashes before response completion.
