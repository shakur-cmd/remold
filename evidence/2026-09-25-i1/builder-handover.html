Corrected claims from the first handover

  • "Refused after rollback" was overstated. The old "compatible-enforcing-rollback" phase restored the expanded schema and kept running the I1 code; no code was rolled back. The IV showed that a real code rollback to 3339517 brings hidden fields back and widens scoped reads. The release gate now refuses such a target. The replay's rollback phase still only proves a schema rollback on I1-or-later code.
  • "All 43 H0 groups are mapped to named production tests" was a string match only. 18 rows were wrong. The guard now checks that each mapped test actually performs the group's operations. The guard's limit: it checks which operations are performed, not assertion meaning, so a verifier should still read the mapped tests.
  • "A new route or function fails the test" was true for functions only. It now also holds for sub-routes and any unparsed branch in the agent REST dispatcher. Adapter routes are derived from the route table and the explicit names.
  • "Mutant wildcard-cutoff is caught" came from a status-code change, not a widening. Removing only the identity.granted cutoff is not observable, because the read cutoff still refuses (404). The reworked mutants remove both cutoffs, or expand migration over all objects, and are caught only when a post-freeze create returns 200.
  • Internal inventory labels are now swept, not just declared, for every operator write that touches a workspace, and for the adapter settlement routes checked in the internal sweep (bind, page and callback). The remaining internal functions sit behind swept routes.

Known limits

  • Workspaces frozen before this revision have no recorded frozen keys, so they fall back to current keys (the D7 behaviour). Nothing with I1 has been deployed, so no workspace is affected.
  • Readonly tail: one send can still be consumed within the 1-second permit window (see Your calls).
  • Two tests race the pause sweep that a role or grant change schedules. They accept either specific refusal ("Approver authority changed" or "Stale claim"; "External capability denied" or "Stale claim"). The final-permit authority check is proven separately by the grant-expiry test, where there is no sweep, and by the h0-final-permit mutant.
  • The financial finality adapter is still SIM. Hosted log sinks were not checked.
