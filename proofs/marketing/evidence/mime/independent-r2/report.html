Limitations

  • This is SERVICE level only: no SMTP, no mailbox, no provider.
  • Date freshness and calendar validity are not checked. A shape-valid but impossible Date, or any 32-hex Message-ID, can vary without changing the hash, but neither can carry free text.
  • The boundary-collision variant is a host-side substitution into real queued bytes. Only the positive control is worker-produced.
  • The boundary replay's inspectMime(changed) throw has no message match. This doesn't block, because the replay also asserts the bridge 409, the sealed state and 0 receiver POSTs.
  • Receipt-only retry still uploads the bytes to the bridge for content validation. /ack only does accounting.
  • My one read-only count on the old guard.sqlite updated its -shm index file. No data changed.
  • The runners overwrote the top-level evidence files. Pre-run copies are in pre-run-top-level/ and my copies are in runs/. Root restores the historical files.
  • No required checks were skipped or blocked. I added no extra native fixture. I did not run the launcher script in the task because it would start another agent.
