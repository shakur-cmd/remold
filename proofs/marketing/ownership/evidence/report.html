Why the first approach failed

Opus source consultation traced native7.2.1 tracking →merge →loser deletion →DNC cascade, with no DNC-copy listener. Native API reads of old IDs resolve merge aliases. Existing capture adapter explicitly refuses a returned contact-ID mismatch; the old ownership baseline intentionally exposes aliases to record the failure.

Kiosk mode avoids the merge for a unique existing email. Capture-only intake removes native identity matching from this path altogether. Installed SubmissionModel saves results separately and accepts no managed lead; ContactTracker returns null for the fixed Blocked-Tracking cookie. This is transport-controlled configuration, never a client-selected cookie or permission to change consent.
