What changed

All files are confined to ops/migrations. package.json and the isolated pnpm lock pin @convex-dev/migrations 0.3.6, convex-helpers 0.1.124 and Convex 1.46.0. The nested workspace allows the same esbuild install step already used by the project. Root production dependencies, schema and deployment configuration were not changed by this slice.

fixture.ts seeds only the scratch deployment. backfill.ts uses the real component and a deterministic injected failure. rehearse.mjs copies core source to a new temporary directory, links installed dependencies, starts anonymous local Convex on reserved ports 3440/3441, and executes the checks. rollback.mjs refuses an undeclared source hash or incompatible schema hash before source deployment.
