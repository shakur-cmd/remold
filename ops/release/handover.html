Independent review correction

The independent C0 verifier caught that a PR target tip may advance past a feature branch. The initial workflow wrongly required that tip to be an ancestor. A real temporary Git graph now reproduces the failure (evidence/merge-base-red.txt). The workflow resolves a PR diff baseline through its single common ancestor, preserving exact feature-head checkout. Push events still use the original before commit and reject non-ancestor history. The same graph test passes after correction and proves unrelated target-branch changes do not enter the PR diff. Ambiguous merge bases fail closed.

Files and commands

release.mjs builds and verifies local candidates. release.test.mjs uses Node's built-in test runner and temporary real files/processes. notes.json declares expand class and the C0 rollback target; it is candidate metadata, not a compatibility certificate. A later schema expansion must name its actual compatible expanded target.

pnpm verify:release
node ops/release/release.mjs build /tmp/new-candidate FULL_HEAD_SHA FULL_BASE_SHA ops/release/notes.json
node ops/release/release.mjs verify /tmp/new-candidate FULL_HEAD_SHA TRUSTED_MANIFEST_SHA256
node ops/release/release.mjs preflight /tmp/new-candidate FULL_HEAD_SHA TRUSTED_MANIFEST_SHA256

Build requires a clean checkout, no local environment files, a base ancestor, valid notes and a previously nonexistent output directory outside the repository. It runs pnpm test, pnpm typecheck, release behavior tests, MCP tests/build and Vite build sequentially. It checks cleanliness again, writes version.json, inventories build files, seals and verifies the manifest. A failed check produces no sealed release. The CLI provides no deploy operation.

The manifest digest must come from the trusted build invocation or trusted CI metadata, separately from the artifact being inspected. This is integrity verification, not cryptographic provenance signing or independent certification. /version.json is a static artifact proposal; the required deployed /version route and Worker version routing are still open.

preflight refuses an undeclared rollback target or different schema digest. Persisted changes always remain blocked until a real restored-snapshot runner and its independent evidence are integrated. Cosmetic CSS/assets/docs can skip snapshot validation; TS/TSX changes conservatively require persisted classification. No generic schema compatibility inference is attempted.
